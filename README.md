# 💳 Interactive Visa Card

An interactive Visa Card built with **HTML**, **CSS**, and **JavaScript**.

## ✨ Features

- Real-time card number update
- Cardholder name updates instantly
- Expiration date synchronization
- CVV display on the back of the card
- Card flips automatically when the CVV input is focused
- Responsive design
- Smooth animations and transitions

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
